# The Odin Project - Landing Page

A responsive and visually clean landing page built as part of **The Odin Project** foundation curriculum. This project focuses on mastering advanced **CSS Flexbox layout techniques**, maintaining semantic HTML architecture, and writing clean, scalable stylesheets.

---

## 🚀 Features

* **Advanced Flexbox Controls**: Utilizes responsive, dynamic global flex configurations with clean fallback overrides (e.g., `justify-content` configurations).
* **Modern Semantic HTML5**: Fully structured layout utilizing `<header>`, `<main>`, `<section>`, and `<footer>` tags for search and accessibility optimization.
* **Component-Driven CSS**: Organized variables and global design rules to keep the styling sheet clean and maintainable.
* **Responsive Scaffolding**: Built from the ground up to support consistent distribution of element spacing.

---

## 🛠️ Built With

* **HTML5**: Standard semantic structure.
* **CSS3**: Custom variables, specific hierarchy management, and comprehensive Flexbox configurations.

---

## ⚙️ How to Run Locally

You can test and view this landing page instantly on your machine by following these steps:

1. **Clone the repository** to your local environment:
   ```bash
   git clone https://github.com
   ```
2. **Navigate into the project directory**:
   ```bash
   cd LandingpageOdin
   ```
3. **Open the project**:
   * Double-click the `index.html` file to launch it directly in your default browser.
   * Alternatively, use the **Live Server** extension in Visual Studio Code for real-time live preview updates.

---

## 💡 Key Lessons Learned

During the development of this landing page, particular emphasis was placed on:
* Structuring flexible layout flows without breaking component alignments.
* Leveraging native CSS properties and fallbacks (`var(--property, default)`) to construct modular helper classes.
* Fine-tuning layout specificity metrics to prevent container scaling bugs.
